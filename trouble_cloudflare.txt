ROOT-CAUSE UPDATE
-----------------
The evidence now distinguishes two separate failure classes:

A. Resolver availability failures:
   Cloudflare/Bun does not accept the tested 5.18.0 and 5.14.20 package versions for the affected packages.

B. MUI package export/build compatibility failure:
   The exact 5.16.14 family installs successfully under Bun, but React Scripts/Webpack 5 compilation rejects the default export from `@mui/utils/chainPropTypes`.

Therefore do NOT claim that all same-version MUI packages are automatically build-compatible. The 5.16.14 family has now been empirically rejected by the actual Cloudflare build.

WHY 5.16.6
-----------
The 5.16.6 release is selected as a compatibility rollback inside the same MUI v5 line, rather than another arbitrary major/minor jump. Published package evidence shows the 5.16.6 family and its internal dependency structure are available. The MUI source for the 5.16.14 line still defines `chainPropTypes` as a default export, so the Cloudflare failure is tied to the published build artifact/packaging path rather than the source-level function definition. The immediate purpose of 5.16.6 is to avoid the published 5.16.14 build behavior that Cloudflare has empirically rejected.

IMPORTANT: 5.16.6 is a new test baseline, not yet a claim of successful Cloudflare deployment. The next Cloudflare build is the required validation.
