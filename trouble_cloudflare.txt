ROOT-CAUSE UPDATE
-----------------
The recurring error is specifically connected to the MUI v5 package/export boundary used by the React Scripts/Webpack build.

MUI's published v5 changelog records that `@mui/utils` 5.15.7 changed its export/build approach and removed an unnecessary default export. This is relevant because the failing import is a default import from `@mui/utils/chainPropTypes`.

The tested 5.16.14 and 5.16.6 families both reproduce the `chainPropTypes` default-export failure. Therefore another same-family 5.16.x rollback is not an adequate strategy.
