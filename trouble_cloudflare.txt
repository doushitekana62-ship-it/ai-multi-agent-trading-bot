The next failure is a separate CRA/Browserslist configuration error:
Error [BrowserslistError]: /opt/buildhome/repo/fronted contains both .browserslistrc and package.json with browsers

ROOT CAUSE OF CURRENT ERROR
---------------------------
fronted/package.json already contains a browserslist configuration with production and development targets. A second fronted/.browserslistrc file contained the same configuration. The installed Browserslist package explicitly rejects having both configuration locations in the same project.

FIX APPLIED — 2026-08-31
-------------------------
Deleted fronted/.browserslistrc from main because package.json is already the canonical Browserslist configuration for this CRA project.

Commit: e72641ad1e9863d30b52f22c137989e9d50507cb

Do not solve this by changing MUI, React, Node, Webpack, or trading architecture. The error is deterministic and isolated to duplicate Browserslist configuration.

------------------
Material UI's official installation documentation confirms React 18 is supported and that MUI Material is installed with Emotion peer dependencies. The published @mui/utils package exposes the relevant utility modules; therefore repeatedly patching individual missing exports is not an appropriate fix.
